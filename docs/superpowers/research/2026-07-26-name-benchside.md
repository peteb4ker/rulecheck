# Name Availability Research: "Benchside"

> **Superseded 2026-07-28:** the app was renamed **Benchwise -> Rule Check** (Xcode project `Benchside` -> `RuleCheck`). This document is kept as the record of what was decided at the time; the names below are historical.

Date: 2026-07-26
Candidate: **Benchside** (app name for Pokemon TCG rules reference, iOS)

## 1. App Store search

**HARD COLLISION — an app named exactly "Benchside" is already live on the iOS App Store.**

- **Benchside** — https://apps.apple.com/us/app/benchside/id6445801735
  - Developer: Reforce Labs Inc
  - Category: Sports
  - Description: "Easily Track Your Home Town's Sports Teams. Compete with Other Fans and Teams"
  - Released: August 14, 2023; Last updated: November 4, 2023 (looks low-activity/possibly dormant, but the listing is still live and indexed — 4 ratings, 5.0 stars)
  - Free
  - Also indexed at: https://www.appbrain.com/appstore/benchside/ios-6445801735 and https://benchside-ios.soft112.com/ (mirror/aggregator listings)

This is an exact-name match in the same store (iOS), different category (Sports vs. Reference/Utilities), different developer. Apple does not guarantee name uniqueness across developers, but:
- It creates direct App Store search confusion — a user searching "Benchside" will see this app first (it has an established listing, install base, ratings).
- Apple review has in the past challenged near-identical app names, especially if the incumbent complains; low but nonzero rejection/dispute risk.
- SEO/ASO for a new "Benchside" is compromised out of the gate — can't own the term in search or as an exact-match domain-style listing.

Close variants checked, no additional iOS collisions found beyond generic "Bench"-named apps (Bench Lifestyle, Benches, BenchApp, Bench, BenchLine, BenchSentry, Benchie, bench.coach, BenchVue) — none of these are "Benchside" or close enough to matter beyond the exact match above.

## 2. Google Play (cross-platform awareness)

No "Benchside" app found on Google Play via web search or a direct Play Store search-results fetch (https://play.google.com/store/apps/details, https://play.google.com/store/search?q=benchside&c=apps — no Benchside listed; only generic "Bench"-named apps: Bench Lifestyle, BenchApp, Bench Gym Log, Bench HR, ServiceBench Mobile).

Cross-platform collision risk on Android: **low** (name is free there), but irrelevant to the harder blocker on iOS above since Benchside is planned as an iOS-only app.

## 3. Trademark search

**Inconclusive via automated web search tools — recommend a direct manual check**, but no evidence found of a live "Benchside" trademark registration.

- tmsearch.uspto.gov is a JS-rendered search app; WebFetch could not retrieve query results (only the static page shell). A manual search at https://tmsearch.uspto.gov/search/search-information should be run before committing to the name.
- trademarks.justia.com: searched "benchside" directly and via site-restricted search — **no "BENCHSIDE" trademark record found**. Numerous "BENCH" marks exist (BENCH. footwear/retail — Deichmann SE & Suyen Corp; BENCH — Bench Accounting Inc, accounting services; BENCH — Bench Computing Inc, AI software, filed March 2025; BENCHLY — Benchly Inc, legal document software) but none are "Benchside" and none appear to be a phonetic/spelling near-miss that would typically block a distinct compound mark.
- EUIPO/WIPO: no specific "Benchside" record surfaced via web search of euipo.europa.eu / wipo.int Global Brand Database; would need a direct database query to confirm (not accessible via WebFetch in this pass).
- Notably, "benchside" is a standard English word (side of a bench) per Wiktionary (https://en.wiktionary.org/wiki/benchside) — this actually *helps* on trademark distinctiveness risk (harder for anyone to claim broad exclusive rights over a dictionary word) but also means it's a plausible, low-friction name for many unrelated businesses to have picked already (see below).

**Recommendation:** run a real TESS/TMSearch and TMclass (EUIPO) query by hand (or via a paid clearance search) before filing anything — this pass could not execute a live database query, only web-indexed mentions.

## 5. TCG-space collision check

**No collision found.** No card, product, tournament, content brand, YouTube channel, or community tool named "Benchside" turned up in Pokemon TCG-specific searches. Searches surfaced only the ordinary TCG usage of "bench" as game terminology (PokeBeach's "Mind the Bench," bench-damage mechanics articles, etc.) — not a naming collision. This is the one dimension where the name is genuinely clear.

## Bottom line

**Not clear — recommend dropping "Benchside."** The blocking issue is #1, not trademark: there is a live, currently-listed iOS app named exactly **"Benchside"** (Reforce Labs Inc, Sports category, id6445801735) already in the App Store. That's a direct, same-channel, exact-name collision — the same category of problem that killed "TopCut" (topcut.cards existing in-space), except here the collision is in the exact distribution channel Benchside would ship to, with an exact string match, not just an adjacent domain.

Secondary concerns reinforcing "drop it":
- The word is already in active use by half a dozen unrelated brands (pharma research tool, Niagara magazine, Sounders FC seating product, Stanford bioethics service, courtroom YouTube channel) — more name noise than any prior candidate, meaning weak claim to ASO/SEO ownership and real user-confusion risk even setting the App Store collision aside.
- Trademark picture is not obviously blocked (no live "BENCHSIDE" mark found), but this pass could not run a real TESS/EUIPO database query — treat trademark as "no red flag found, not fully cleared."

What's clear: no collision in the Pokemon TCG community itself — if the App Store/naming-noise issues could somehow be waived, the TCG audience wouldn't be confused. But the App Store exact-name collision alone should be disqualifying under the same bar that eliminated the three earlier candidates.

**Recommendation: reject "Benchside," go back to candidate generation.** If there's appetite to revisit, a formal manual USPTO TESS search plus a WHOIS check on benchside.com/.app should be run regardless, but they're moot given the App Store finding.
