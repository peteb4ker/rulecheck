# Benchside replacement — app name candidates

Context: "Benchside" is dead (exact-name collision, apps.apple.com id6445801735).
Prior casualties: "Prof's Companion" (existing tutoring business), "TopCut"
(topcut.cards), "Rulepoint" (Informatica trademark), any Pokemon character/
species name or "Poke-" prefix (trademark-radioactive, off the table
permanently).

Audience: Pokemon TCG players and judges/professors. DNA that resonates:
TCG-vocabulary words used generically (bench, deck, prize, judge, prof),
short, warm, ownable.

## Round 1 — 12 candidates generated

1. Deckside
2. Benchwise
3. Rulebench
4. Sidebench
5. Judgecall (Judge Call)
6. Prof Desk
7. Tablejudge (Table Judge)
8. Bench Notes
9. Judge Bench
10. Prize Row
11. Roundcall
12. Matchwise

Six strongest selected for full screening (best fit on DNA + gut check for
memorability): **Deckside, Benchwise, Rulebench, Judgecall, Prof Desk,
Tablejudge**.

## Round 2 — screening

Screens run per candidate: (a) `site:apps.apple.com "<name>"`, (b) general
web search for products/companies/trademarks, (c) `site:trademarks.justia.com
"<name>"`, (d) TCG-community collision check.

### 1. Deckside — CLEAN

- App Store: no exact-match app. Search surfaced only generic deck-themed
  apps (Decks!, Card Decks, Deck Planner, DeckAI, etc.) — no collision.
  https://apps.apple.com/us/app/decks/id1556892591 (unrelated)
- Trademark: one hit, "DECKSIDE" filed 2021 by Deckside, LLC, but for
  **footwear, hats, shirts** (apparel class) — unrelated goods/services,
  low real risk for a software app.
  https://trademarks.justia.com (Deckside, LLC, Serial No. 90840423)
- General web: no active app/company/product using the name in tech or
  gaming.
- TCG community: no hits for "Deckside" + Pokemon TCG.
- **Verdict: cleanest DNA-continuation candidate, no meaningful collisions.**

### 2. Benchwise — MOSTLY CLEAN, one watch-out

- App Store: no exact match. Adjacent names found (Bench, Benches, Bench
  Lifestyle, BenchWorth, BenchmarkMe) plus **Benchside itself** still
  listed (confirms it's dead) — https://apps.apple.com/us/app/benchside/id6445801735
- General web: two existing companies named "BenchWise":
  - BenchWise (life-science product-review platform, Stanford-founded,
    **now permanently closed**) — benchwise.org, LinkedIn
    https://www.linkedin.com/company/benchwise
  - Benchwise Solutions (Dubai/Melbourne telecom & renewable-energy firm,
    founded 2014) — active LinkedIn/Crunchbase presence
    https://au.linkedin.com/company/benchwise-solutions
    https://www.crunchbase.com/organization/benchwise
- Trademark: no registered "Benchwise" trademark found on Justia.
- TCG community: no hits for "Benchwise" + Pokemon TCG.
- **Verdict: no App Store or trademark collision, but the name is already
  in active commercial use by an unrelated tech company (Benchwise
  Solutions). Different industry (telecom), so risk is low but not zero —
  worth a gut check before committing.**

### 3. Rulebench — CLEANEST

- App Store: no exact match. Only tangential hits (Reloader's Bench,
  Rules!, Rule It, an academic "OpenRuleBench" PDF) — no collision.
- General web: no active company, product, or app called "Rulebench."
- Trademark: no "Rulebench" entry found on Justia Trademarks.
- TCG community: no hits for "Rulebench" + Pokemon TCG.
- **Verdict: zero collisions found across all four screens. Strongest
  candidate on cleanliness.**

### 4. Judgecall / Judge Call — CLEAN, minor domain watch-out

- App Store: no exact match. Only generic judge-themed apps/games (Judge!,
  Judge AI Conversation Court, You Judge, Judge Simulator, Judge Advocate,
  CompetitionSuite Judge) — no collision.
- General web: **judgecall.com is a parked/for-sale domain** on
  DomainMarket.com — http://judgecall.com/ — no live product or company
  using the name. Would need to be bought or the app could use a
  different domain/no-domain strategy.
- Trademark: no "Judgecall"/"Judge Call" trademark found; adjacent marks
  (JUDGE UNIFIED COMMUNICATIONS — cancelled 2021; JUDGE IS ASKING, live)
  are not close enough to conflict.
- TCG community: "Judge" is itself a Pokemon TCG Supporter card name
  (thematic overlap only, not a trademark/naming collision — "Judge" is
  a common English word, TPCi doesn't own exclusive rights to it for an
  unrelated reference app). No product called "Judge Call" found in the
  TCG space.
- **Verdict: clean on App Store/trademark/community. Only watch-out is the
  parked judgecall.com domain (would need purchase or a workaround like
  judgecallapp.com).**

### 5. Prof Desk — COLLISION, existing active company

- App Store: no exact match on apps.apple.com.
- General web: **"Prof-desk" is an existing company** — a free online
  learning management system (LMS) for high-school teachers/students,
  with active LinkedIn (https://www.linkedin.com/company/prof-desk) and
  Twitter/X (https://x.com/ProfdeskIT) presences.
- Trademark: no registered "Prof Desk" trademark found, but the unregistered
  active use above is still a real-world naming collision risk.
- TCG community: no hits for "Prof Desk" + Pokemon TCG; general search
  surfaced the (unrelated) official Pokemon TCG "Professor Program."
- **Verdict: name collision with an active education-software company —
  same broad "professor/teacher tool" positioning as part of our own
  audience (judges/professors). Recommend dropping.**

### 6. Tablejudge / Table Judge — COLLISION, direct in-space conflict

- App Store: **direct hit.** The existing app "Judges Toolkit for Pokemon"
  (https://apps.apple.com/us/app/judges-toolkit-for-pokemon/id1170164207)
  has a named feature called **"Table Judge"** — round logs / game-log
  tool for singleton actions (Supporter, Stadium, Retreat, Energy
  attachment) at a table. This is the same community, same product
  category (Pokemon TCG judging tools), essentially the same phrase.
- Also worth noting for context: tcgjudge.com ("TCG Judge — Pokémon TCG
  rules + Standard card lookup") is a very close positioning match to our
  own app's mission (though the name itself isn't "Table Judge," it's an
  adjacent competitor worth being aware of).
- General web / trademark: no formal "Tablejudge" trademark, but the
  in-space App Store collision alone is disqualifying.
- **Verdict: too close to an existing feature in a direct-competitor
  Pokemon TCG judging app. Drop.**

## Round 3 — ranked shortlist (survivors only)

1. **Rulebench** — no collisions found on any of the four screens (App
   Store, general web, Justia trademarks, TCG community). Short, warm,
   plainly readable, describes the product literally (a bench of rules).
   Good App Store searchability since "rule" + "bench" are both terms
   players/judges actually search.
2. **Judgecall** — clean on App Store/trademark/community; directly names
   the judge audience without being generic ("Deck Check"-style) or a
   character name. Slight residual watch-out: judgecall.com is parked, so
   domain acquisition or an alternate TLD/suffix would be needed.
3. **Deckside** — cleanest continuation of the original Benchside DNA
   (same rhythm, "-side" pattern); only trademark hit is an unrelated
   apparel-class registration, negligible risk for software.
4. **Benchwise** — no App Store or trademark collision, but the name is
   already used by an active, unrelated-industry company (Benchwise
   Solutions, telecom/renewables) and a defunct one (BenchWise life
   sciences). Lowest of the four due to that residual "already exists"
   feeling, even though not enforceable.

Dropped from further consideration: **Prof Desk** (collides with an active
education LMS company of near-identical name) and **Tablejudge** (collides
with a named feature — "Table Judge" — inside an existing direct-competitor
Pokemon TCG judging app).
